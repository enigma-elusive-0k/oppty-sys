# Changelog

## 1.0.0 (2026-09-04)

Initial release. Claude-only package.

- Engine: SYSTEM.md with bootstrap, capability detection, three persistence modes, ten-step Live Fire workflow, cross-cutting rules.
- Onboarding: seven checkpointed steps with progress indicators and resume-from-interruption.
- Modules: Sourcing, Evidence Standard, Voice Guide, Interview Prep, Outreach, Red Team Review, DOCX Build.
- Templates: tracker, cover letter skeleton, CONFIG and STATE templates.
- Example: one anonymized Live Fire walkthrough.
